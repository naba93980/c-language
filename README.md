# C Language

A collection of C programs and practice code written while learning the fundamentals of the C programming language.

## About

This repository contains C source files created while learning programming. It serves as a personal collection of code examples, experiments, and practice exercises written while exploring C.

The repository also includes code organized for different development environments.

## Repository Structure

- `c files code blocks/` — C source files organized for Code::Blocks.
- `c files dev c/` — C source files organized for Dev-C++.
- `c files visual studio/` — C source files organized for Visual Studio.

## Getting Started

You can run the programs using a compatible C compiler or an IDE that supports C development, such as GCC, Code::Blocks, Dev-C++, or Visual Studio.

1. Clone the repository:

   ```bash
   git clone https://github.com/naba93980/c-language.git
   ```

2. Navigate to the directory containing the program you want to run.
3. Open the source file in your preferred editor or IDE.
4. Compile and execute the program using the appropriate tools for your environment.
